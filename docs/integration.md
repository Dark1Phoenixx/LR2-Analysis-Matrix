# Документация интеграции

## Назначение и архитектура

ЛР №3 продолжает проект «Анализ матрицы» из ЛР №1–2. Матрица не хранится целиком: для позиции `(i, j)` вычисляется `sin(i + j / 2)`, после чего считается число положительных значений.

`input_module.validate_request` проверяет JSON-конверт и размерности. `processing_module.count_positive_elements` содержит вычислительный алгоритм. `worker.handle` объединяет проверку и вычисление. `integration.run_file` запускает worker, передавая ему JSON-файл запроса и получая JSON-файл ответа. `output_module.format_result` готовит человекочитаемый вывод.

## Направление интеграции и поток

Используется восходящая интеграция из варианта 20. Сначала алгоритм обработки проверяется напрямую тестовым драйвером. Затем к нему добавляется файловый JSON-обмен и worker. После этого подключаются валидация входа и форматирование ответа.

`count_positive_elements` → `worker.handle` → `request.json` / `response.json` → `integration.run_file` → `format_result`.

Заглушки не требуются: нижний модуль можно запускать напрямую, а тесты служат драйверами до появления верхнего orchestration-слоя.

## Протокол и сопоставление полей

Транспорт — обмен файлами в UTF-8 JSON. Текущая версия схемы равна `1`.

| Источник | Поле | Проверка или преобразование | Получатель |
| --- | --- | --- | --- |
| JSON-запрос | `protocol_version` | Должно быть целым значением `1` | Worker проверяет совместимость |
| JSON-запрос | `payload.rows` | Положительное целое, `bool` запрещён | Input проверяет; Processing задаёт число итераций по строкам |
| JSON-запрос | `payload.columns` | Положительное целое, `bool` запрещён | Input проверяет; Processing задаёт число итераций по столбцам |
| Processing | `positive_count` | Число элементов, для которых `sin(i + j / 2) > 0` | Output форматирует для пользователя |
| JSON-ответ | `status` | `ok` либо `error` | Integration решает, принять результат или поднять ошибку |

Пример запроса:

```json
{"protocol_version":1,"payload":{"rows":2,"columns":3}}
```

Пример успешного ответа:

```json
{"protocol_version":1,"status":"ok","data":{"rows":2,"columns":3,"positive_count":5}}
```

## Запуск

Из корня репозитория: `python -m src.integration examples/request.json --output response.json`. Тесты: `python -m unittest discover -s tests -v`.
