# План тестирования

Вариант 20, проект «Анализ матрицы» из ЛР №1–3, уровень 3. Основной метод —
комбинаторное покрытие условий. Инструмент — Python unittest. Порог по операторам
и по сумме операторов и ветвей — 75%.

## Сценарии

- Вход: шесть достижимых комбинаций для версии протокола, неверный корень
  JSON и payload, типы размерностей и значения −1, 0, 1 и 2 для каждой оси.
- Вычисления: 1×1 → 0, 2×3 → 5, 5×1 → 3. В последнем случае индекс i от 0 до 4
  даёт нулевой, положительные и отрицательный синусы.
- Вывод: JSON с кириллицей сохраняется в UTF-8, массив отклоняется, итоговое
  сообщение содержит размеры и счётчик.
- Worker: корректный запрос даёт статус ok и код 0, rows=0 — статус error и код 1.
- Файловый сценарий: настоящий subprocess получает запрос, создаёт ответ
  и передаёт данные на сохранение. Для таймаута, отсутствующего и повреждённого
  ответа используются подмены subprocess.run.
- Регрессия: тип версии ответа, полнота результата, согласованность размерностей
  и счётчика, импорт src.main и обработка ошибочного JSON без файла результата.

## Матрица условий версии

A: версия не int, B: версия bool, C: версия не равна 1. Решение об ошибке
вычисляется как A or B or C. Вектор показывает значения отдельных предикатов,
даже когда Python пропускает их из-за короткого замыкания.

| Значение | A | B | C | Ошибка |
| --- | --- | --- | --- | --- |
| 1 | 0 | 0 | 0 | нет |
| 2 | 0 | 0 | 1 | да |
| True | 0 | 1 | 0 | да |
| False | 0 | 1 | 1 | да |
| 1.0 | 1 | 0 | 0 | да |
| "1" | 1 | 0 | 1 | да |

Векторы 110 и 111 недостижимы: bool является подклассом int.
Решение по версии проверено на оба исхода. Проверка размерностей охватывает
оба исхода предикатов типа и границы и оба поля. Для условия подсчёта
проверены положительный, нулевой и отрицательный аргумент сравнения с нулём.

## Запуск

```bash
python -m pip install -r requirements-dev.txt
python -m flake8 src tests --max-line-length=120
python -m unittest discover -s tests -p test_regression.py -v
python -m coverage erase
python -m coverage run -m unittest discover -s tests -v
python -m coverage combine
python -m coverage report --fail-under=75
python -m coverage json
```

## Контрольный прогон

Python 3.12.14, Linux. Успешно пройдены 35 из 35 тестов, включая 5 тестов
регрессии. Протоколы запуска и показатели по модулям приведены в отчёте.
Покрытие операторов — 96,88%, ветвей — 90,48%, суммарное — 95,54%.
Проценты покрытия получены с учётом дочерних процессов worker.
