# Техническое задание

## 1. Введение

### 1.1 Наименование программы
«Анализ матрицы».

### 1.2 Краткая характеристика области применения
Программа предназначена для подсчета количества положительных элементов матрицы размерности n × m, элементы которой вычисляются по формуле a_ij = sin(i + j/2). Может использоваться в учебных целях, для математического моделирования, а также как компонент более сложных вычислительных систем.

## 2. Основания для разработки
Разработка выполняется в рамках лабораторной работы №1 по дисциплине «Инструментальные средства разработки программного обеспечения» согласно учебному плану специальности 09.02.07 «Информационные системы и программирование».

Наименование темы разработки: «Разработка программы подсчета положительных элементов матрицы».

Шифр темы: «Матр-01».

## 3. Назначение разработки
Программа должна:
- запрашивать у пользователя размерность матрицы n и m;
- проверять корректность ввода;
- вычислять значение каждого элемента по формуле a_ij = sin(i + j/2);
- подсчитывать количество элементов, удовлетворяющих условию a_ij > 0;
- выводить результат в понятном формате.

## 4. Требования к программе
Программа разрабатывается на языке Python и использует стандартную математическую библиотеку math. Входные и выходные данные — текстовые.
