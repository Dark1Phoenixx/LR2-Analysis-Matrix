# LR2

## Название проекта
Лабораторная работа №2 — проект «Анализ матрицы».

## Краткое назначение
Проект предназначен для анализа матрицы на Python и освоения работы с системой контроля версий Git.

## Требования к окружению
- Python 3.11+
- Git
- Git Bash

## Инструкция по запуску
1. Открыть Git Bash.
2. Перейти в папку проекта.
3. Запустить программу командой `python src/main.py`.

## Стратегия ветвления
В проекте используется упрощённая схема Git Flow: ветка `main` содержит стабильное состояние проекта, а ветка `develop` используется для разработки и проверки изменений. После завершения работы изменения из `develop` объединяются с `main`. Для небольшого учебного проекта такая схема наглядно показывает назначение основной и рабочей веток.
